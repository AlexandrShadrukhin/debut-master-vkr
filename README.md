# ДебютМастер

Репозиторий содержит исходный код и материалы выпускной квалификационной работы по теме разработки веб-приложения «ДебютМастер» для игры в шахматы и интерактивного обучения шахматным дебютам.

## Структура репозитория

- `frontend/` — клиентская часть приложения на React, TypeScript и VKUI.
- `backend/` — серверная часть приложения на Java Spring Boot.
- `docs/` — текст ВКР и дополнительные материалы.

## Основной функционал

- локальная игра в шахматы;
- игра против компьютерного соперника Stockfish;
- онлайн-партии через игровые комнаты;
- обучающие сценарии по шахматным дебютам;
- тактические задачи;
- тест начального уровня;
- итоговый тест;
- расчёт эффективности обучения;
- панель прогресса пользователя.

## Технологии

Frontend: React, TypeScript, VKUI, VK Bridge, chess.js, react-chessboard, Stockfish.

Backend: Java 17, Spring Boot, Spring Data JPA, WebSocket/STOMP, PostgreSQL.
